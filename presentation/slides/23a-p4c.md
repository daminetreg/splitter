notes: A different corpus, and a third contender. p4c is the P4 compiler: 218 translation units of ordinary C++20 -- an IR, a frontend, a midend -- with one interned string type, cstring, that every unit includes. Its members are defined in the class, so they are inline and every includer carries them. CMake's unity build is the usual answer to a slow build: it concatenates units into batches of 8 and compiles the batch. Here it is measured against the split on the same machine, -j16, build phase only: plain, unity, splitter.

// lib/cstring.h: interned strings, included by every unit
namespace P4 {
class cstring {
    const char *str = nullptr;
 public:
    // Size tests. Constant time except for size(),
    // which is linear time.
    size_t size() const {
        return str ? strlen(str) : 0;
    }
    bool isNull() const { return str == nullptr; }
    const char *begin() const { return str; }
    const char *end() const {
        return str ? str + strlen(str) : str;
    }
